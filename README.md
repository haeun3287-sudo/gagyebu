# 퀵가계부 (1단계 · 개인용)

금액만 톡 기록하고, 나중에 회상하며 정리하는 가계부입니다.

## 폴더 안 파일
| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱의 뼈대 (화면 틀, 하단 메뉴) |
| `style.css` | 색, 글자 크기, 모양 (맨 위 색상 값만 바꾸면 전체 색이 바뀜) |
| `app.js` | 앱의 두뇌 (기록, 회상, 내역, 요약, 카드 내역 읽기) |
| `manifest.webmanifest` | 폰 홈화면에 설치될 때 이름과 아이콘 |
| `sw.js` | 인터넷이 없어도 앱이 열리게 해줌 |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |
| `vendor/xlsx.full.min.js` | 엑셀 파일 읽기 도구 (SheetJS, Apache-2.0) |

## 자주 고칠 곳 (app.js)
- **카테고리**: 맨 위 `TREE`
- **기본 자동 분류 규칙**: `DEFAULT_RULES`

## 데이터는 어디에?
- 기록은 **이 폰의 브라우저 안에만** 저장됩니다. 서버로 보내지 않습니다.
- 브라우저 데이터를 지우면 사라지니 **설정 › 백업 파일 받기**를 가끔 해주세요.
- 깃허브에 올라가는 건 앱 코드뿐이고, 내 지출 기록은 올라가지 않습니다.

## 고친 뒤 반영하기
깃허브 저장소에서 파일을 바꾸면 1~2분 뒤 폰 앱에 자동 반영됩니다. (앱을 한 번 껐다 켜기)
